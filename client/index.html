Why is this screen showing?

You launched this using VS Code's "Go Live" / Live Server. Live Server only works for static HTML. Modern React applications use Vite to compile JSX files (.jsx), bundle npm packages, and process Tailwind CSS on the fly.

How to start the live application:

  1. Install Node.js: If not installed yet, download the LTS version from nodejs.org or ask your assistant to install it.
  2. Install dependencies: Open your terminal and run:
    npm run install:all
  3. Start development server:
    npm run dev
  4. Open your browser: Navigate to http://localhost:5173
When the Vite dev server starts, React will automatically mount and replace this message with your live interactive dashboard.
